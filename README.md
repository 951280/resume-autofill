# 简历秒填 · Resume AutoFill

一个纯本地的 Chrome 扩展：在任意招聘网站的表单页上，自动识别字段、用你的简历一键回填，
**填完逐项高亮待确认，提交永远由你自己点**。

- 不绑定站点：靠字段语义识别，不写死某个招聘网站
- 不联网：简历数据存在本机 `chrome.storage.local`
- 不自动提交：这是故意的，自动投递既违反多数平台规则，填错就是错误投递

---

## 安装

1. 打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目的 **`dist`** 目录
4. 首次安装会写入一份**虚构的示例简历**，点插件图标 →「编辑简历」改成自己的真实信息

> 修改代码后重新构建，然后在扩展页点一下刷新按钮即可。

## 使用

在招聘表单页上有三种方式唤出面板：

- 页面右下角的「填写」气泡（页面有 ≥3 个可填写控件时自动出现）
- 快捷键 `Alt + Shift + F`
- 点浏览器工具栏上的插件图标 →「打开填写面板」

面板流程：**扫描本页字段 → 核对预览列表 → 勾选要填的 → 填充选中**。

| 颜色 | 含义 |
|---|---|
| 绿色描边 | 高置信匹配，默认已勾选 |
| 黄色描边 | 低置信匹配，需要你确认 |
| 紫色字段名 | 来自「自定义字段」，或 AI 补识别的结果 |

字段被写进去后描边会保留，你在该字段里输入或修改时描边自动消失。

## 本地试一下

仓库自带一个模仿招聘网站的演示表单，可以先拿它练手：

```bash
python -m http.server 8000 --directory demo
# 然后打开 http://127.0.0.1:8000/apply.html
```

注意：只能用 `http://` 打开，直接双击 `file://` 打不开——content script 只注入 http/https 页面。

## 能识别什么

内置中英双语词典，覆盖这些字段（括号内是常见叫法）：

| 分类 | 字段 |
|---|---|
| 基本信息 | 姓名、英文名/拼音、性别、出生日期、年龄、手机号、邮箱、微信、QQ、现居城市、详细地址、籍贯、政治面貌、民族、国籍、婚姻状况、身份证号、GitHub、个人主页 |
| 求职意向 | 期望职位、期望城市、期望薪资、工作性质、到岗时间、每周实习天数、可实习时长、工作年限 |
| 教育经历 | 学校、专业、学历、入学时间、毕业时间、GPA、排名 |
| 工作经历 | 公司、职位、入职时间、离职时间 |
| 项目经历 | 项目名称、项目角色、项目时间、技术栈、项目链接 |
| 其它 | 工作内容/职责描述、自我评价、专业技能、证书、获奖、语言能力 |

识别时综合 `label` / `placeholder` / `aria-label` / `name` / `id` / 表格左侧单元格 /
Ant Design、Element Plus、Arco 的 form-item 标签，并用所在区块标题（教育经历 / 工作经历…）消歧——
比如同样是「职位」，在「求职意向」里填意向岗位，在「工作经历」里填任职职位。

## 自定义字段

招聘表单里总有些奇怪的问题：「紧急联系人」「是否服从调剂」「档案所在地」「英语四级分数」。
在 **设置页 → 自定义字段** 里按「`表单上的标签名` → `填写内容`」配置，匹配到就直接填。

示例简历里预置了几条自定义字段，可以照着格式继续加。

## AI 补识别（可选，默认关闭）

规则没认出来的字段，可以点面板上的「AI 补识别」，把控件信息发给大模型判断字段归属。

- 走 **OpenAI 兼容协议**，任何提供 `/chat/completions` 的服务都行（DeepSeek、通义、自建网关…）
- 地址 / 模型 / API Key 都在设置页填，**Key 只存本机**
- 只有你手动开启开关、并手动点按钮时才会发请求
- AI 给出的结果默认**不勾选**，需要你自己确认

## 隐私

- 简历数据全部在 `chrome.storage.local`，没有任何后端，没有账号体系
- 除你主动开启 AI 补识别外，插件不发起任何网络请求
- 卸载插件或清除浏览器数据会一并删除，建议定期用「导出」备份成 JSON
- 身份证号这类敏感字段请自行判断是否要填进简历库

## 已知限制

- **文件上传**（简历附件、证件照）无法自动填写，这是浏览器安全限制，需要手动选文件
- **验证码 / 滑块 / 短信校验**不处理
- **多段经历**目前只填第一段（最近一段）；页面上有多组「公司/职位」时只会填第一组
- **富文本编辑器**（Quill、ProseMirror 等）可能写不进去
- **跨域 iframe**：每个能填的 frame 会各自出现一个面板，而不是统一成一个
- 高度定制化的下拉（`div` 模拟的 select）可能选不中

### 目录结构

```
src/
  background/       Service Worker：安装初始化、快捷键转发
  content/
    scanner.ts      采集页面控件与上下文文本（label / 相邻文本 / 区块）
    matcher.ts      词典 + 正则 + 区块加权打分，含自定义字段匹配
    filler.ts       写值并派发 input/change（兼容 React/Vue 受控组件）
    overlay.ts      Shadow DOM 面板 UI
    index.ts        串起扫描 → 预览 → 填充 → 高亮
  options/          简历编辑器与设置页（React）
  popup/            工具栏弹窗
  shared/
    dictionary.ts   字段词典、负向词、区块关键词
    values.ts       按字段从简历取值、日期格式化
    storage.ts      chrome.storage 封装
    llmClient.ts    OpenAI 兼容接口
    defaultProfile.ts  示例简历（来自 Excel 模板）
tools/              图标生成、Excel 导出脚本
demo/               本地演示表单
test/               jsdom 回归测试
```

### 想加一个字段

1. 在 `src/shared/types.ts` 的 `FIELD_KEYS` 里加 key
2. 在 `src/shared/dictionary.ts` 的 `RULES` 里加一条规则（`patterns` 写中文叫法，`negative` 写排除词）
3. 在 `src/shared/values.ts` 的 `resolveValue` 里加取值分支
4. 在设置页 `App.tsx` 加编辑入口
